📖 Panduan Penggunaan ×

Mode Edit — klik tombol ⚙ di pojok kanan bawah untuk membuka panel pengaturan dan mengaktifkan mode edit. Angka skor/set/VC/T-O/SUB bisa ditambah dengan klik biasa kapan saja. Selama mode edit aktif, tombol "−" kecil muncul di setiap angka, dan menahan (tekan lama) atau klik kanan pada angka akan menguranginya.

Skor & Statistik — klik angka untuk menambah (bisa di luar mode edit juga). Untuk mengurangi, aktifkan mode edit lalu klik tombol "−" merah, tekan lama, atau klik kanan pada angka.

Akhiri Set — tombol "Akhiri Set →" mencatat skor set saat ini ke kotak riwayat set, menambah jumlah set pemenang, lalu me-reset skor & statistik untuk set berikutnya. Skor akhir TIDAK direset otomatis, jadi penonton tetap bisa melihat hasil akhir sampai Anda menekan tombol ini.

Jam Pertandingan — klik jam untuk mulai/jeda saat mode edit tidak aktif. Saat mode edit aktif, klik jam untuk mengetik ulang waktunya secara manual. Klik kanan jam atau tombol "Reset Timer" akan meminta konfirmasi sebelum me-reset.

Font & Warna Skor — pilih jenis huruf (termasuk Black Ops One), warna isi angka, dan warna outline angka besar dari panel pengaturan.

Iklan Video/Audio — unggah klip video atau audio di panel pengaturan. Klik ▶ pada daftar iklan untuk memutarnya layar penuh tanpa tombol pemutar, berulang (loop) sampai layar diklik. Volume memudar masuk/keluar agar penonton tidak kaget. Iklan audio mengingat posisi terakhirnya (lanjut dari situ saat diputar lagi) dan bisa ditumpuk sebagai antrean — gunakan tombol "Lagu Berikutnya" di layar untuk berpindah ke iklan audio berikutnya.

Panel Pengaturan — panel ini bisa digeser (drag) ke posisi mana pun dengan menahan bagian judul di atas. Klik ikon 🎯 di judul panel untuk mengembalikannya ke posisi semula.

Kustomisasi Kontrol — buka "⌨️ Kustomisasi & Cetak Kontrol" untuk mengganti tombol keyboard pintasan, atau mencetak lembar referensi kontrol.

Keyboard (default): Q/A skor A, U/J skor B, W/S set A, I/K set B, N akhiri set (hanya saat mode edit aktif) — T timer, F layar penuh, H buka/tutup panel (selalu aktif). Tombol ini dapat diganti lewat menu Kustomisasi Kontrol.
